# KOLEY CONSTRUCTION – Static Website

A single-page, real-life style construction company landing site built with **HTML**, **CSS**, and **JavaScript**.

## Features

- Modern, responsive layout (desktop, tablet, mobile)
- Hero section with animated stats
- About, Services, Projects, Why Us, and Contact sections
- Smooth scroll effects and basic form validation

## Getting Started

1. Download or clone this project.
2. Open `index.html` in any modern browser (Chrome, Edge, Firefox, etc.).
3. That’s it – no build step or dependencies are required.

For a better developer experience, you can also open the folder in VS Code/Cursor and use a “Live Server” extension to auto-reload on changes.
